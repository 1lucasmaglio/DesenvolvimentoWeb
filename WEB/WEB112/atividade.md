# Parte 3 - WordPress

# 1. O que é um tema no WordPress?
É o que define a aparência do site, como as cores e o layout.

# 2. O que é um plugin? Dê 2 exemplos.
É uma ferramenta que adiciona funções ao site. Exemplos: formulário de contato e SEO.

# 3. Qual a diferença entre página e post?
Página é usada para informações como "Sobre" e "Contato". Post é usado para notícias e artigos.

# 4. O WordPress é gratuito? Explique.
Sim, o WordPress.org é gratuito, mas pode ser necessário pagar pela hospedagem e pelo domínio. O WordPress.com tem um plano gratuito e outros pagos.
